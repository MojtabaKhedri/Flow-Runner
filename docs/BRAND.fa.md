# هویت Flow Runner

- نام محصول: **Flow Runner**؛ نام بستهٔ توسعه: `flow-runner`.
- نشان: همان حرف F با نقطهٔ مرجانی در مربع قرمز نسخهٔ قبلی؛ فایل SVG و آیکن‌های Chrome از یک هندسه ساخته می‌شوند.
- رنگ اصلی قرمز `#e4002b`، پس‌زمینهٔ دارک `#202425` و متن `#e8e2d8` است.
- فونت تمام رابط وزیرمتن است و فایل آن همراه افزونه قرار دارد.
- رابط فارسی و دکمهٔ پاور مرکزی است؛ دکمه ثابت و بدون هاله یا بافت نویز نمایش داده می‌شود.
- نام Flow Runner و نشان F در پنل، راهنما، حریم خصوصی، اطلاعات Chrome و بستهٔ انتشار استفاده می‌شوند.

مسیر نصب و شناسه‌های فنی نسخهٔ قبل برای سازگاری ثابت مانده‌اند؛ تنظیم روشن/خاموش با تغییر برند پاک نمی‌شود. برای دریافت نسخهٔ جدید، همان افزونه را در صفحهٔ مدیریت Chrome بازخوانی کنید.
